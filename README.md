# 旗舰突击 · 六海征途

独立的第三人称 3D 单机海战。Three.js + Vite，电脑和手机浏览器直接玩；运行不需要 Godot、RPG 或游戏服务器。与 `godot_world_voyage` 平级。

在线游玩：<https://lemonhall.itch.io/flagship-six-seas>（itch.io）｜<https://flagship-arena-web.lemonhall.me>（自有域名；备用 <https://flagship-arena-web.vercel.app>）。生产桌面/手机模拟已验证船模加载、真实开炮与暂停。

## 怎么玩

- 左摇杆 / WASD 掌舵，松手后旗舰保持巡航。
- 让侧舷朝向敌舰，按住「排射」/ 空格，自动瞄准当前目标、逐门开炮。
- 「换目标」/ Q 切换目标，相机跟随目标，保持旗舰与敌舰在前方视野。
- 「冲刺」/ Shift 短时加速，4.5 秒冷却。
- 橡木桶修船、铁炮弹箱补弹，驶近自动吸附；炮弹按实际炮门消耗。
- 两艘友舰由 AI 控制，沉没后有补舰。敌人会绕行、避礁和避炮；风暴逐步收圈。
- 每击沉一波三艘普通敌舰，战场暂停，三选一改装：加炮门、加快装填、燃烧与殉爆、冲刺反击，或应急加固。改装在本关有效。
- 敌舰会造成明显伤害；有限的维修桶需要争取，不能依靠友军和免费维修一路挂机。
- 首领是普通船身长度 2.6–3.5 倍的巨舰，五种攻击包括扇形封锁、预判曲射、巨舰冲撞、横扫排射和包夹轰炸。红线提前固定，及时变向、留冲刺突围；半血暴怒后攻击更密、间隔更短。装填破绽增伤 35%，首阶段持续 3.2 秒、暴怒阶段 2.6 秒。详见 [巨舰首领调整](docs/boss-pressure.md)。

背景音乐默认为 60%，首次点击起航或音乐控件后循环播放。开战前的菜单和战斗中的「BGM」按钮都能调节音量、关闭音乐；音量与开关会保存在当前浏览器，和炮击音效分别控制。切到后台时暂停播放。音乐使用独立的 Web Audio 增益控制，以支持 iPhone 上的音量调节。

手机菜单随浏览器可视高度调整，保留底部安全留白；更矮的屏幕可以上下滑动到起航按钮。

战斗区会拦截连点和双指操作产生的浏览器缩放手势，避免排射时意外放大网页；菜单仍可上下滑动。详见 [移动触控修复记录](docs/mobile-touch-zoom-fix.md)。

波间改装界面会避开原炮击区域，返回航路入口在弹窗左上方。松开手指或按键、停止连点约半秒后，才可选择改装或返回，避免炮击连点误选或退出本局；竖屏卡片可在弹窗内上下滑动。详见 [改装误触修复记录](docs/upgrade-input-fix.md)。

## 六关与奖励

| 航路 | 普通波数 | 首领 | 通关奖励 |
|---|---:|---|---|
| 翡翠浅滩 | 3 | 灰帆船长 | 双桅快船、葡萄弹散炮 |
| 珊瑚水道 | 3 | 铁钩船长 | 大帆船、曲射臼炮 |
| 断桅群岛 | 4 | 疾风海盗 | 地中海快舰、长管炮 |
| 风暴边缘 | 4 | 赤潮舰长 | 巡航舰 |
| 沉船海峡 | 5 | 黑旗提督 | 战列舰 |
| 王者航路 | 5 | 深海霸主 | 宝船 |

常态三友三敌。每三个普通敌人为一波，击沉后 1.8 秒补充；末尾首领和两艘护卫同时入场，护卫全场最多补充四次。击沉首领通关，旗舰沉没失败。新局随机岛礁，单关最长六分钟。巨舰首领版新存档自动驾驶走完六关共十场，包含四次失败；成功场 72–112 秒。二周目宝船六关 52–112 秒。这些是固定策略的规则验证，真人操作和选择用时不同。

加农炮逐门排射，轻炮装填快，散弹炮近距离覆盖，臼炮高抛越过岛礁并造成范围伤害，长管炮适合远射。弹药、命中、障碍遮挡和船体火力都由纯模拟计算。

## 船坞成长、宝船与二周目

击沉普通敌舰得 2 零件，每完成一波另得 3 零件，首领另有奖励。失败或主动返回也能带回本次已获得的零件，重复结算不会重复发奖。船坞有三条各三级的永久强化，升级费用依次为 12 / 22 / 36 零件：火炮每级伤害 +10%，船壳每级船体 +8%，操舵每级航速 +4%、冲刺冷却 -10%。敌人不会因为你升级而同步变强。

每波改装与船型特长可以搭配：双桅快船和地中海快舰冲刺更快，大帆船维修多 25%，巡航舰装填快 10%，战列舰每轮多一门，宝船每轮多两门。

已解锁的船炮永久保留在当前浏览器的本机存档。宝船有 850 船体、175% 基础火力，可以选旧关自由重玩。

通关全部六关后，可从结算或航路菜单开启下一周目。全部装备继承，六关进度重新推进。每提升一周目，敌舰船体 +20%、伤害 +12%，玩家火力 +12%、装填时间减少 7 个百分点；倍率最多累计五次，继续挑战仍记录周目。二周目宝船实际单发加农伤害 49，初始卡拉维尔为 25。

存档只保存在各自浏览器、各自网站域名下的 `localStorage`，不会上传，也不会写进分享网址。别人打开同一网址会从自己的进度开始；同一浏览器同一域名的标签页使用同一份本地进度。换设备、换浏览器或使用备用域名不会自动同步。

存档键为 `flagship-progress-v2`，内容是可读 JSON：`cleared` 为永久解锁进度，`voyage` / `voyageCleared` 为周目进度，`rewards` 为对局奖励账本，`training` 为强化等级。旧 `flagship-progress-v1` 自动迁移，船炮与周目保留，每个已通关关卡补偿 8 零件，最多 48，且只补偿一次。旧周目重玩不会覆盖最新进度。浏览器禁止写存储时保留会话进度并提示，清除网站数据会清除本机存档。周目编号校验上限 999。

## 本地运行与验证

需要 Node.js 22.12+（本机与生产验证使用 Node 24）。在本目录运行：

```powershell
npm ci
npm run dev
npm test
npm run e2e
npm run build
node tools/analyze-balance.mjs
```

开发服务监听局域网，可在同一 Wi-Fi 的手机访问 `http://192.168.50.250:5173`。E2E 使用系统 Chrome。30 项 Node 行为测试和 13 项浏览器测试覆盖六关实弹与改装、五种首领攻击、巨舰模型与命中范围、赚取/购买/失败/再战、两个浏览器存档隔离、桌面和手机控制、连续触摸缩放防护、改装弹窗连点与长按防误触、390×667 / 320×480 / 844×390 布局、BGM 循环及音量。截图保存在 `evidence/`；手机验证为 Chrome 模拟，未代替真机 Safari 验收。

平衡工具保留种子 1–12 的全部胜负。巨舰首领报告为 `evidence/boss-pressure-balance.json`（240 场 + 新存档完整战役，包含源码哈希）；首关停船 0/12 胜、固定转圈开炮 1/12，相同 AI 策略初始 2/12、三项各升一级 6/12、满级 11/12。它用于检查威胁与成长差异，不等同于真人胜率。通过 `node tools/analyze-balance.mjs evidence/boss-pressure-balance.json` 重建；旧报告 `combat-balance-v2.json`、`combat-balance-baseline.json` 保留用于对照。

## 资产复用

使用原游戏 134 种船型中的七艘，及原橡木桶/炮弹箱几何。来源记录在 `public/assets/ships/manifest.json`。Godot 帆布 Shader 转为标准双面亚麻材质，保留几何；Meshopt 压缩将九个 GLB 从 36.68 MiB 减到 6.05 MiB。按关卡加载，首关只下载卡拉维尔、双桅快船和两种补给，约 1.44 MiB。

重建资产，在仓库根运行 Godot 工具，再进入本目录打包：

```powershell
& 'E:/Godot_v4.7.2-stable_win64.exe/Godot_v4.7.2-stable_win64_console.exe' --headless --path godot_world_voyage --script tools/export_flagship_web_assets.gd
cd flagship-arena-web
node tools/pack-assets.mjs
```

原始导出位于忽略的 `.cache/godot-exports`。提交的 `public` 已包含可直接运行的压缩资产；仅开发时重新导出才需要 Godot。

> 本仓库已于 2026-10-01 从 `blender-tests` 独立出来。上面两条命令里的 `godot_world_voyage` 目录与 `tools/export_flagship_web_assets.gd` 都在父仓库 `blender-tests` 中，只有重新导出船模资产时才需要回去执行；日常开发、测试与发布都在本仓库内完成。

BGM 是 `public/audio/six_seas_bgm.mp3`：**Pirate Indenture**（Eldritch Grim），取自 [OpenGameArt](https://opengameart.org/content/pirate-indenture)，**CC0 1.0 公有领域奉献**——可自由使用、修改与再分发，且无需署名。原曲 38 秒，本项目用 ffmpeg 循环 5 次拼成约 190 秒（CC0 明确允许修改），128 kbps MP3、2.9 MiB。先前的《让我们荡起双桨（重金属）》是仍在版权保护期内的改编曲，已移除，避免公开分发风险。

## 结构与部署

- `src/i18n.js`：中英双语与语言检测。语言按 `?lang=` → `localStorage` → `navigator.language` 解析，英文优先；数据表与 DOM 更新用内联 `L(zh, en)`，固定标记用 `data-i18n`。
- `src/catalog.js`：关卡、船炮与周目倍率。
- `src/progression.js`：本地存档、旧版迁移、零件奖励和永久强化。
- `src/upgrades.js`：波间候选与实际武器改装。
- `src/bosses.js` / `geometry.js`：首领状态机、海面预警与共享几何规则。
- `src/sim.js`：无 DOM 的固定步长模拟、AI、炮弹、补给、增援和胜负。
- `src/view.js`：GLB、第三人称相机、海面、随机岛礁和限量特效。
- `src/controls.js` / `audio.js`：键鼠/多指输入、黑火药音效与循环 BGM。
- `src/selection-guard.js`：改装弹窗的松手与连点结束检测。
- `src/main.js`：菜单、HUD、存档和流程。开发验收驱动不会进入生产包。
