# PRD-0002：压力、改装与首领

2026-09-20。用户已批准 [复盘方案](../combat-design-review.md) 并要求实装。关联 [ECN-0002](../ecn/ECN-0002-combat-growth.md)。

## Vision

浏览器和手机玩家只操控旗舰，通过躲避、争取射界、波间选择，从起步吃力成长到火力成型。失败带来可保留的零件，BOSS 有可识别和可躲避的招式与反击窗口。六关完整实现，不止首关演示。

## 契约与边界

- 普通敌人三槽，友军两槽+旗舰；快速补充，六关波数和随机岛礁不变。
- `upgradeChoices` 是当前可选改装 ID，`chooseUpgrade(id)` 验证后生效；临时改装只在本关有效，永久训练进入下一场初始属性。
- 成长存档写入 `flagship-progress-v2`，旧 v1 为迁移来源；旧玩家补偿按已通关数一次性计算。余额由累计获得与已购等级计算，结算使用对局 ID 去重。
- BOSS 预警与伤害使用同一世界坐标；锁定后不追踪玩家；暂停与改装同时冻结招式时钟。
- 不增加战斗操作按钮、复杂背包、账号/付费/云存档、联机；不修改 Godot RPG。复用现有船模和音乐。
- 具体伤害、血量与时序可在上述行为目标内调校。2–3 分钟/关、友军约 25–35% 输出是调校参考，真人趣味性最终仍需用户试玩，不能用模拟冒充。
