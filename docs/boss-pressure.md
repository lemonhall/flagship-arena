# 巨舰首领与封路攻击

2026-09-20，用户验收反馈：BOSS 体型与攻击仍缺少压迫感。本轮在独立 Web 单机版增强巨物观感、攻击组合与躲避压力，复用现有船模。

## 行为约定

- 六关首领船长约为普通船的 2.6–3.5 倍，船体命中范围、冲撞宽度、海面标记、尾流与名称高度同步。保持现有血量，压力主要来自招式。
- 首阶段每个首领至少两种招式。五种攻击为扇形封锁、预判曲射、巨舰冲撞、逐段横扫、留缺口的包夹轰炸。
- 开始预警时依据旗舰航向和速度预测落点；红线固定后不再追踪玩家。预警显示完整的伤害范围，炮弹寿命内标记不能提前消失。
- 半血增加攻击密度、缩短准备和间隔；保留明确准备时间、突围路线及攻击后的增伤破绽。不能依靠偷偷移动红线或不可躲的满屏伤害制造难度。
- 仍然使用实体炮弹与曲射弹道，维持三友三敌、手机操作、已有奖励和本地存档。

## 验收

规则测试覆盖新招式实伤与逃离、锁定后不追踪、实际伤害与预警一致、扩大船体命中、半血变化及弹量上限。完整战役使用真实炮击、真实改装和赚取的强化，不注入胜负。固定种子平衡报告保留失败；桌面和手机截图检查巨舰、红线及操作区域。

## 实现与结果

| 航路 | 首阶段招式 | 暴怒新增招式 | 船身倍率 |
|---|---|---|---:|
| 翡翠浅滩 | 扇形封锁、预判曲射 | 横扫排射 | 2.60 |
| 珊瑚水道 | 预判曲射、横扫排射 | 包夹轰炸 | 2.78 |
| 断桅群岛 | 巨舰冲撞、扇形封锁 | 预判曲射 | 2.96 |
| 风暴边缘 | 横扫排射、预判曲射、扇形封锁 | 包夹轰炸 | 3.14 |
| 沉船海峡 | 巨舰冲撞、包夹轰炸、横扫排射 | 预判曲射 | 3.32 |
| 王者航路 | 包夹轰炸、横扫排射、巨舰冲撞、预判曲射 | 扇形封锁 | 3.50 |

扇形封锁从 5 条航道增加到暴怒时 7 条，每条 4/5 发；横扫依次扫过 5/7 个方向，每条 3 发。曲射为 5/7 个落点，包夹在外围留下一个缺口、中心最后爆炸。炮击准备 1.2/0.95 秒，冲撞准备 1.35/1.1 秒；落弹额外飞行 1.05 秒。每轮后准备间隔 4.25/3.25 秒，增伤破绽持续 3.2/2.6 秒。

每发首领炮弹绑定自己的预警 ID，标记持续至最后一发到达。冲撞红线宽度、两端圆弧与实际扫掠范围一致；遇礁停止，不挤到标线外。模型保持船体居中，放大海面圈与尾流，近距离锁定巨舰时镜头略后退；出场、冲撞与重炮有对应水花和低沉音效。
