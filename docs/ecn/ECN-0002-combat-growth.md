# ECN-0002：战斗压力与成长

2026-09-20，用户试玩发现难度与成长不足，已批准复盘中的改版方案。

原设计 PRD-0001 以六关可完成、船炮解锁和二周目为主要验收，无局内改装或零件成长；BOSS 只有武器与数值差异。

新设计由 PRD-0002 REQ-0002-001–007 定义：有效威胁、波间三选一、永久强化、失败收益、独立 BOSS 招式与六关体验验证，以及用户补充的浏览器本地存档隔离。保留原单机范围、资产、音乐、船炮解锁、周目及随机地形。

影响：纯规则、存档协议、UI、3D 预警与测试。旧“所有自动驾驶必须轻松获胜”不再是平衡验收；改为差异策略与成长对照，同时保留实际炮击完整战役路径。

处置：PRD-0002、v2-index、v1 后续记录已同步；测试与实现按 v2 计划推进。用户本轮已授权，没有额外审批步骤。
