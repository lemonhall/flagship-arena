# ECN-0001：先验收单机，新增宝船二周目

日期：2026-09-20。关联 [PRD-0001](../prd/PRD-0001-arena.md)、[v1-index](../plan/v1-index.md)。

影响：`catalog.js` 进度协议、`sim.js` 火力倍率、`main.js` 航路和结算、Node 与浏览器验收。旧存档迁移、旧周目不覆盖新进度、宝船真实战斗都进入验证。
