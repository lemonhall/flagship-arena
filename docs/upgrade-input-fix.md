# 波间改装误接炮击连点

2026-09-20，用户反馈：连续点击排射时突然弹出改装界面，原炮击位置可以点到「收拢战利品 · 返回航路」，意外结束本次出航。

## 原因与修复

原弹窗会立即启用所有按钮，并把焦点移到首个改装选项。清空游戏输入状态并不代表玩家已经松手；尚未结束的连续点击、长按按键会被新界面接住。手机上的底部返回按钮还占用了原炮击区域。

- 返回航路入口移到弹窗左上方。竖屏下方、横屏左右永久留出战斗操作区域，按钮解锁后也不会占用原炮击位置。矮屏仅在弹窗内部滚动卡片。
- 弹窗独立跟踪实际指针与按键状态。所有手指、按键释放后，需要连续 450 毫秒没有新输入，才能启用按钮；持续连点会重新计时。
- 弹出时聚焦对话框本身，避免长按空格激活预选按钮。等待时显示「松开手指，稍候选择改装」。
- 正常选择后恢复当前战斗，只有主动点击顶部返回才结算离场。

## 验证

新增 `tests/browser/upgrade-input.spec.js` 两项回归。修复前确实失败：原炮击位置连点误选改装并恢复战斗；空格仍按住时改装按钮已启用。修复后两项通过：

- 实弹推进至波间弹窗，保持火炮手指按住，再于原位置连续触摸 12 次，保持战斗暂停且没有选择或离场。
- 按住空格跨入弹窗，松开后继续每 100 毫秒点击一次，选项保持锁定；停止后正常解锁，主动返回能带回 9 零件。
- 解锁后检查 390×667、320×480、844×390，所有弹窗按钮与原炮击区域至少间隔 12 像素；选择改装只生效一次。
- 三项成长回归通过，包括手机卡片可滚动到达、失败再战与本地存档隔离。
- 其余七项浏览器回归通过，包含完整六关、奖励继承再战、移动双指控制、连续炮击缩放防护和 BGM；共 12 项通过。
- `npm run build` 通过，保留 Three.js 既有 chunk 大小提示。
- Vercel 生产部署 `dpl_Gd1iDFzk4eDrYDQ2gS7mXPVeJjKA` 为 READY。正式域名执行 `node tools/verify-live.mjs` 返回 `PRODUCTION_OK`，确认已提供顶部返回入口；桌面与手机模拟的船模、实弹炮击、连续触摸缩放防护、音乐和独立本地存档通过，无页面脚本错误。记录位于 `evidence/production.json`。
